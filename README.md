# Libft

## Description

Libft is a static C library (`libft.a`) that reimplements standard libc
functions and adds utility and linked-list functions. It will be reused in
later 42 projects.

## Instructions

```bash
make        # build libft.a
make clean  # remove .o files
make fclean # remove .o files and libft.a
make re     # fclean + all
